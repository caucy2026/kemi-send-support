KEMI Send Support

Official help for KEMI Send on macOS

Getting started

  1. Install and open KEMI Send on two devices connected to the same local network.
  2. Allow Local Network access when macOS asks.
  3. On the sending device, select a nearby device and choose a file, folder, text message, or clipboard item.
  4. Accept the transfer on the receiving device and choose where to save it.

The core local-network transfer features do not require an account.

Troubleshooting

  • If devices do not appear, confirm both devices are on the same Wi-Fi or LAN and Local Network access is enabled.
  • If a transfer cannot start, check the receiving device is awake and KEMI Send is running.
  • If saving fails, choose a folder for which macOS has granted access.

Ask a question or request support

Open a support request and include your macOS version, KEMI Send version, the steps you performed, and any visible error message. Do not include passwords, private files, or other sensitive information.

Privacy

Local-network transfers are sent directly between devices. KEMI Send does not upload transferred files to this support site.
